# Настройка Telegram-уведомлений для формы обратной связи

Для того чтобы форма на сайте начала отправлять сообщения в Telegram, необходимо развернуть Google Apps Script и обновить URL в `index.html`.

## Шаг 1. Развертывание Google Apps Script

1. Перейдите на [script.google.com](https://script.google.com).
2. Создайте новый проект.
3. Скопируйте содержимое файла `telegram_bot_script.gs` из этого репозитория в редактор скриптов.
4. Нажмите **«Развернуть»** → **«Новое развертывание»**.
5. Выберите тип **«Веб-приложение»**.
6. В поле **«Кто имеет доступ»** выберите **«Все»** (Anyone).
7. Нажмите **«Развернуть»** и скопируйте полученный **URL веб-приложения**.

## Шаг 2. Обновление index.html

1. Откройте `index.html`.
2. Найдите строку:
   ```javascript
   const scriptUrl = 'YOUR_SCRIPT_URL'; // ВСТАВИТЬ URL ВЕБ-ПРИЛОЖЕНИЯ
   ```
3. Замените `'YOUR_SCRIPT_URL'` на URL, полученный на предыдущем шаге.
4. Сохраните файл.

## Шаг 3. Проверка

1. Откройте сайт в браузере.
2. Заполните форму и нажмите «Отправить заявку».
3. Проверьте Telegram-бота на наличие нового сообщения.
